# Harri Proyecto Github 1.1

Proyecto TechZone preparado para GitHub Pages.

## Archivos
- `index.html`
- `styles.css`
- `script.js`

## Cambios de esta versión
- Se reemplazó el título “30 pantallas: 5 por cada tecnología” por “Monitores y pantallas”.
- Se eliminaron ASUS ProArt IPS 27, Samsung Odyssey VA 32, ASUS ROG Swift OLED 32, Dell Alienware OLED 27 y ASUS ProArt Mini-LED 32.
- La sección refleja ahora 25 pantallas y los conteos correctos por tecnología.
- Las tarjetas de pantallas usan el mismo conjunto y formato de botones del catálogo principal: Ver detalles, Comparar, Favorito y Carrito.
- Se reforzó la uniformidad visual, el ajuste de textos y el comportamiento adaptable en computadoras, tabletas y teléfonos.
- Se conservaron las funciones existentes: catálogo, filtros, búsqueda, carrito, favoritos, comparador, modales, imágenes seleccionables y menú móvil.

- Se unificaron colores, botones, estados hover/focus y tamaños táctiles con un estilo digital abstracto.
- Se reforzó la compatibilidad responsive para escritorio, tablet y móvil, evitando desplazamiento horizontal y mejorando grids/modales/paneles.
- Fecha de revisión: 6 de agosto de 2026.

## Publicación en GitHub Pages
Sube los tres archivos principales a la raíz del repositorio. GitHub Pages abrirá `index.html` y cargará `styles.css` y `script.js` mediante rutas relativas.
